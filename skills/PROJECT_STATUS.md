## 📋 后续开发准备

### 1. 环境配置

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.local.example .env.local
# 编辑 .env.local 填入：
# - DATABASE_URL (PostgreSQL 连接字符串)
# - NEXTAUTH_SECRET (随机字符串)
# - NEXT_PUBLIC_SUPABASE_URL (可选)
# - NEXT_PUBLIC_SUPABASE_ANON_KEY (可选)

# 3. 初始化数据库
npx prisma generate
npx prisma db push

# 4. 启动开发服务器
npm run dev
```

### 2. 数据库迁移

```bash
# 创建迁移
npx prisma migrate dev --name <migration_name>

# 应用迁移
npx prisma migrate deploy

# 重置数据库
npx prisma migrate reset
```

### 3. 代码规范

```bash
# 运行 ESLint
npm run lint

# 类型检查
npx tsc --noEmit
```

## ⚠️ 开发限制

### 1. 技术限制

| 限制项 | 说明 |
|--------|------|
| Node.js 版本 | >= 18.0.0 |
| PostgreSQL 版本 | >= 14.0 |
| 浏览器支持 | 现代浏览器 (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+) |
| 最大任务数 | 单用户建议 < 10000 个任务 |
| 文件上传 | 当前不支持 |

### 2. 功能限制

| 限制项 | 说明 |
|--------|------|
| 任务层级 | 仅支持一级子任务 |
| 重复任务 | 仅支持简单 RRULE（每日、每周、每月） |
| 时间范围 | 排程仅支持当天 |
| 链接解析 | 仅支持公开可访问的网页 |
| 并发用户 | 单实例建议 < 100 并发用户 |

### 3. API 限制

| API | 限制 |
|-----|------|
| /api/tasks | 分页，默认 100 条 |
| /api/schedule | 单次最多生成 7 天 |
| /api/links/parse | 超时 10 秒 |
| /api/auth/register | 无速率限制（建议添加） |

### 4. 已知问题

1. **排程算法**
   - 仅排程当天任务
   - 不支持跨日任务
   - 不支持时区处理

2. **拖拽排序**
   - 拖拽后时间计算可能不准确
   - 大量任务时性能下降

3. **链接解析**
   - 部分网站可能解析失败
   - 不支持需要登录的页面
