## 快速开始

### 注册账号

1. 访问 [PlanManage 网站](/)
2. 点击"注册"按钮
3. 填写邮箱、密码和姓名
4. 点击"注册"完成账号创建

### 登录

1. 访问 [PlanManage 网站](/)
2. 点击"登录"按钮
3. 输入邮箱和密码
4. 点击"登录"进入系统

### 界面概览

登录后，您将看到以下界面：

- **顶部导航栏**: 包含 Logo、导航菜单和用户头像
- **侧边栏**: 快速访问各个功能模块
- **主内容区**: 显示当前页面内容

## 任务管理

### 创建任务

1. 点击左侧菜单的"任务"
2. 点击右上角的"新建任务"按钮
3. 填写任务信息：
   - **任务标题** (必填): 任务的名称
   - **任务描述** (可选): 任务的详细说明
   - **预计耗时** (必填): 完成任务预计需要的时间（分钟）
   - **权重** (1-10): 任务的重要程度
   - **优先级**: 低、中、高、紧急
   - **任务类型**: 工作、学习、个人、健康、其他
   - **截止时间** (可选): 任务的截止日期
   - **来源链接** (可选): 任务相关的网址
4. 点击"创建任务"保存

### 编辑任务

1. 在任务列表中找到要编辑的任务
2. 点击任务右侧的"..."菜单
3. 选择"编辑"
4. 修改任务信息
5. 点击"保存修改"

### 删除任务

1. 在任务列表中找到要删除的任务
2. 点击任务右侧的"..."菜单
3. 选择"删除"
4. 在确认对话框中点击"删除"

### 完成任务

- 点击任务左侧的圆圈图标即可标记任务为已完成
- 完成任务后，系统会自动插入休息时间

### 子任务

#### 创建子任务

1. 创建新任务时，在"父任务"下拉菜单中选择父任务
2. 或者在任务详情页点击"添加子任务"

#### 查看子任务

- 在任务列表中，子任务会显示在父任务下方
- 子任务有独立的进度条显示完成情况

### 重复任务

#### 创建重复任务

1. 创建新任务时，开启"重复任务"开关
2. 设置重复频率：每天、每周、每月
3. 设置重复间隔
4. 设置重复次数（0 为无限重复）

#### 编辑重复任务

- 编辑重复任务时，可以选择编辑单个实例或所有实例

### 筛选和搜索

- **搜索**: 在搜索框中输入关键词搜索任务
- **状态筛选**: 按任务状态筛选（未开始、进行中、已完成、已延期）
- **优先级筛选**: 按优先级筛选（低、中、高、紧急）
- **类型筛选**: 按任务类型筛选（工作、学习、个人、健康、其他）

### 分页

- 任务列表支持分页加载
- 点击"加载更多"按钮加载更多任务
- 页面底部显示分页信息

## 时间表

### 查看时间表

1. 点击左侧菜单的"时间表"
2. 默认显示今日视图
3. 可以切换到周视图查看一周的安排

### 生成时间表

1. 点击右上角的"重新排程"按钮
2. 系统会根据任务权重、优先级和截止时间自动排程
3. 固定时间任务会优先安排

### 拖拽排序

1. 在时间表中，拖拽任务项可以调整顺序
2. 拖拽后，系统会自动更新时间

### 休息时间管理

#### 查看休息时间

- 休息时间在时间表中显示为虚线边框的卡片
- 包含咖啡图标和"休息时间"文字

#### 跳过休息

1. 点击休息时间卡片上的"跳过"按钮
2. 或者在休息倒计时界面点击"跳过"按钮

#### 休息倒计时

- 完成任务后，系统会自动显示休息倒计时
- 倒计时界面包含：
  - 环形进度条
  - 剩余时间显示
  - 开始/暂停按钮
  - 跳过按钮
  - 重置按钮

#### 休息结束通知

- 休息结束时，系统会发送浏览器通知
- 需要授权浏览器通知权限

### 周视图

1. 点击"周视图"标签切换
2. 显示一周 7 天的时间安排
3. 每天的时间轴从 6:00 到 22:00
4. 当前时间会用红色线条标记

## 链接解析

### 解析链接

1. 点击左侧菜单的"链接解析"
2. 在输入框中粘贴网址
3. 点击"解析"按钮
4. 系统会提取网页的标题、描述和封面图

### 创建任务

1. 解析链接后，点击"创建任务"按钮
2. 系统会自动填充任务信息
3. 补充其他任务信息
4. 点击"创建任务"保存

### 解析历史

- 所有解析过的链接都会保存在历史记录中
- 可以随时查看和删除历史记录

### 支持的网站

- 通用网页: 提取 og:title、og:description、og:image
- B站视频: 通过 API 获取视频信息
- YouTube: 提取视频封面图

## 设置

### 工作时间设置

1. 点击左侧菜单的"设置"
2. 设置工作开始时间
3. 设置工作结束时间
4. 点击"保存设置"

### 休息时间设置

1. 设置默认休息时长（分钟）
2. 点击"保存设置"

### 默认任务权重

1. 设置新任务的默认权重（1-10）
2. 点击"保存设置"

### 主题设置

1. 点击右上角的主题切换按钮
2. 选择主题：
   - **浅色**: 浅色主题
   - **深色**: 深色主题
   - **系统**: 跟随系统设置

### 头像设置

1. 点击右上角的用户头像
2. 选择"设置"
3. 点击头像区域上传新头像
4. 支持 JPG、PNG、GIF、WebP 格式
5. 最大文件大小 2MB

### 全局快捷键

| 快捷键 | 功能 |

## 常见问题

### Q: 如何重置密码？

A: 
1. 在登录页面点击"忘记密码？"
2. 输入注册邮箱
3. 查收重置邮件
4. 点击邮件中的链接
5. 输入新密码

### Q: 如何导出数据？

A:
1. 点击右上角的用户头像
2. 选择"导出数据"
3. 选择导出格式（JSON/CSV）
4. 选择导出类型（任务/时间表）
5. 点击"导出"

### Q: 如何开启通知？

A:
1. 浏览器会自动请求通知权限
2. 点击"允许"开启通知
3. 如果之前拒绝了，可以在浏览器设置中重新开启

### Q: 任务没有显示在时间表中？

A:
1. 确认任务状态不是"已完成"
2. 确认任务的截止时间是今天或未来
3. 点击"重新排程"重新生成时间表

### Q: 如何设置固定时间任务？

A:
1. 创建或编辑任务
2. 开启"固定时间任务"开关
3. 设置开始时间和结束时间
4. 固定时间任务不会被自动排程移动

### Q: 子任务最多支持几级？

A: 目前仅支持一级子任务，即子任务下不能再创建子任务。

### Q: 重复任务支持哪些频率？

A: 目前支持：
- 每天
- 每周
- 每月

### Q: 如何切换语言？

A: 目前仅支持中文，后续版本将添加英文支持。

### Q: 数据安全吗？

A: 
- 所有数据存储在安全的数据库中
- 密码使用 bcrypt 加密存储
- 使用 HTTPS 加密传输
- 定期备份数据

### Q: 如何联系客服？

A:
- 发送邮件至 support@planmanage.com
- 在 GitHub 提交 Issue
